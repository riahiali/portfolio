Nexor: smart lock platform

Mobile app, backend API and ESP32 firmware for a Bluetooth smart lock.In development · repos: nexor-application, nexorFW

What it is

A React Native app (Expo, TypeScript, Zustand) talks to a lock over Bluetooth LE and to an Express + Prisma + PostgreSQL backend for accounts, invites and activity logs. A WebSocket manager pushes real-time updates.

Firmware

PlatformIO project for ESP32 using NimBLE, with separate modules for BLE, motor, proximity sensor, RTC, power, error log and Wi-Fi OTA.

Security design

The repo includes a written BLE protocol spec: ECDH P-256 pairing, AES-256-GCM encrypted commands, HMAC on each packet and replay protection. The backend has rate limiting, CSRF and HMAC-verification middleware.

AI

None. This project has no AI component.

Document data extraction pipeline

Upload a PDF, get names, dates, organizations, amounts and IBAN-like strings back.Working prototype in code · repo: UIB

How it works

A Next.js front end uploads a PDF to an Express API. The API queues a job with Bull on Redis. A worker starts a Python script that reads the PDF and runs spaCy named-entity recognition plus regular expressions. Results are stored in PostgreSQL and shown in a dashboard.

Honest scope

It uses spaCy’s pre-trained en_core_web_sm model, not a model I trained, and not an LLM. The amount and IBAN patterns are rough regexes.

TradLingo: document translation app

French, English and Arabic translation of administrative documents.Working app with tests · repo: tradlingo · team project

How it works

A Streamlit app calls the Hugging Face Inference API with Helsinki-NLP translation models. French↔Arabic goes through English. Users sign in with accounts stored in SQLite, with PBKDF2-SHA256 hashed passwords. Results are cached in memory.

Reliability

Timeouts, 401/403, 429 quota errors and unsupported languages each raise a clear error. The API key comes from .env. Tests use mocks, so they pass without a key. Ruff and Bandit are in the requirements.
